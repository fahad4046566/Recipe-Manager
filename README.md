# 🍽️ Recipe Manager

A fully responsive CRUD Recipe Manager built with React and Context API.

## 🚀 Features

- Add new recipes
- Delete recipes
- Mark as favorite
- Search by title (real-time)
- Filter by cuisine
- Data persistence using LocalStorage
- Responsive design (mobile + desktop)

## 🛠️ Tech Stack

- React
- Context API
- React Router
- Tailwind CSS
- DaisyUI
- LocalStorage

## 📦 Deployment

Live Demo: https://recipe-manager-3d7q.vercel.app/
